# Q4 - CI pipeline (GitHub Actions)

Size: S. Why: Automatic tests and build on every push / pull request.

Follow the START and FINISH protocol in AGENTS.md (set your row in docs/PROGRESS.md to
IN_PROGRESS first; at the end set it to DONE, commit with the message below, do not push).

TASK Q4 - create .github/workflows/ci.yml, triggered on pull_request and push to main. Use current major versions of the official actions (checkout, setup-java, setup-node).
Job backend (ubuntu-latest): setup-java with the Java version the backend pom requires (temurin) + Maven cache; run "mvn -B -ntp verify" in /backend. Tests use H2 and mocks so no secrets are needed - make sure no test requires real Redis, PostgreSQL or NSE (opt-in live tests stay disabled).
Job frontend (ubuntu-latest): setup-node using the Node version from frontend/package.json engines (or current LTS) with npm cache; in /frontend: npm ci, npx tsc --noEmit, npm run build (dummy env values in the workflow, no secrets).
Fix anything that only fails on clean Linux (path separators, time zone: tests must pass with TZ=UTC and TZ=Asia/Kolkata; Redis not running). Add a CI status badge line to README.md only. Do not touch other README content.
