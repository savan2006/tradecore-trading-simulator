With admin parameters also call admin overview, market-status, audit-logs, and (if present) completeness and reconciliation - read-only.
Print a PASS/FAIL/SKIPPED table and exit non-zero on any FAIL. Never print passwords. Put usage in a header comment. Do not run it yourself.
